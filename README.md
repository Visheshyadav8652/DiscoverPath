# 🚀 DiscoverPath 🌍

*Your AI-powered travel companion, right in your browser!*

---

## ✨ What is DiscoverPath? 

**DiscoverPath** is an intelligent Flask web app that crafts **personalized travel itineraries** for you using the latest in machine learning and route optimization. 🧳🤖  
With interactive maps, data-driven recommendations, and a sprinkle of AI magic, your next adventure starts here!

---

## 🎒 Features

- 🗺️ **Smart Itinerary Generation**: Harness AI to create custom travel plans based on your preferences.
- 📍 **Interactive Maps**: Visualize your route and destinations clearly.
- 🧠 **Machine Learning Route Optimization**: Get the most efficient and fun-packed journeys.
- 📊 **Data-Driven Suggestions**: Discover hidden gems and must-see places.
- ⚡ **Easy-to-Use Interface**: No tech expertise required!

---

## 🏁 Getting Started

#### 1. **Clone the Repo**
```bash
git clone https://github.com/Visheshyadav8652/DiscoverPath.git
cd DiscoverPath
```

#### 2. **Install Dependencies**
Make sure you have Python 3.7+ and pip installed.
```bash
pip install -r requirements.txt
```

#### 3. **Run the App**
```bash
python app.py
```
Go to [http://localhost:5000](http://localhost:5000) in your browser and start exploring! 🌐

---

## 🗂️ Project Structure

- `app.py` — The main Flask application.
- `create_db.py` — Script to set up the database.
- `data/` — Data files for POIs, routes, etc.
- `static/` — Static assets (CSS, JS, images).
- `templates/` — Frontend HTML templates.
- `similarity_matrices.pkl` — Precomputed data for smarter recommendations.
